# pth-release-baseline (SK-13)

Проверяет готовность и при явной просьбе фиксирует снимок. Принятие релиза этим скиллом не делается: скилл даёт вердикт по данным, решение принимает пользователь.

## Вход

- Ключ проекта и, если нужен снимок, его название.
- `PTH_URL` и `PTH_TOKEN`. Для снимка нужна роль writer.

## Шаги

1. Проверь доступ: `sdk/pth me`.
2. Получи готовность: `sdk/pth readiness <KEY>`. Вердикт: `ready`, `not_ready` или `insufficient_data`.
3. Покажи блокирующие элементы (`blocking`) с их статусом. При большом списке сгруппируй по статусу.
4. Если вердикт `ready`, скажи, что это данные, а не решение о релизе. Решение принимает пользователь.
5. Снимок фиксируй только по явной просьбе и с подтверждением: `sdk/pth baseline <KEY> "<название>"`.
6. Список снимков: `sdk/pth baselines <KEY>`.

## Выход

Вердикт готовности, число проверяемых элементов, блокирующие элементы, при необходимости — созданный снимок с его uid и числом артефактов.

## Границы

- Не объявляй релиз принятым и не создавай снимок без явной просьбы и подтверждения.
- `insufficient_data` означает, что данных нет, а не «всё хорошо».
- Вердикт `ready` опирается на свидетельства pass. Не добавляй к нему свои оценки.
